Handcrafted Haven

A virtual marketplace connecting talented artisans with customers who appreciate handcrafted items.

 Project Description
Handcrafted Haven is a web application that allows artisans to showcase and sell their unique handcrafted items. It connects creators with customers who appreciate handmade products.

 Tech Stack
- Front-End: HTML, CSS, JavaScript, Next.js
- Back-End: Node.js, Database
- Deployment: Vercel
- Project Management: GitHub Boards
